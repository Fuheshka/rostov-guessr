# РостовГессер

GeoGuessr по Ростову-на-Дону на панорамах Яндекса. Один HTML-файл, без сборки и бэкенда.

## Как играть

5 раундов. Случайная панорама в пределах Ростова — ставь метку на мини-карте (наведи, чтобы увеличить) и жми «Угадать». Очки: `5000 · e^(−d / 2000 м)`.

Играть: https://fuheshka.github.io/rostov-guessr/

## Ключ Яндекса

Игроку ничего вводить не надо — ключ зашит в `APIKEY` в `index.html`.

1. Получи бесплатный ключ на [developer.tech.yandex.ru](https://developer.tech.yandex.ru/) — «JavaScript API и HTTP Геокодер».
2. В кабинете ограничь ключ по HTTP Referer: `fuheshka.github.io` и `localhost`. Ключ JS API всегда виден в браузере, защита только этим ограничением.
3. Впиши ключ в `const APIKEY = '...'`.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открой `http://localhost:8000`. Другой ключ можно подставить через `?apikey=...`.

## Настройки

В начале `<script>` в `index.html`:

- `ROUNDS` — число раундов
- `BBOX` — границы города для выбора случайных точек
- `K` — насколько быстро падают очки с расстоянием (метры)

## Техника

- Yandex Maps JS API **2.1** — панорамы есть только в нём, в 3.0 их нет.
- Точка выбирается случайно в `BBOX`, ближайшая панорама ищется через `ymaps.panorama.locate` (до 40 попыток).
